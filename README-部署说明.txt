专升本单词练习室 · 手机版 PWA

1. 把此文件夹内所有内容一起部署到支持 HTTPS 的静态网站（例如 Netlify Drop / GitHub Pages）。
2. iPhone：Safari 打开部署网址 → 分享 → 添加到主屏幕。
3. Android：Chrome 打开网址 → 菜单 → 安装应用 / 添加到主屏幕。
4. 使用后四川精选词库可离线练习；三份第三方在线词表需首次联网获取，之后浏览器尝试本地保存。Excel 导入解析依赖在线库；CSV/TXT 可离线导入。
5. 网页数据保存在本机浏览器，清理浏览器站点数据/更换网址可能导致记录丢失。
6. 若直接双击打开 index.html 可以练习，但无法启用完整 PWA 安装和离线缓存。

注意：本版本是 PWA 源文件，不是 APK 或已经发布的微信小程序。
